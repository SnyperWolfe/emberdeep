# Art credits

Every 3D model in `models/` is by **Quaternius** (https://quaternius.com), released under
**CC0 1.0** (public domain). Attribution is not required; it is given anyway.

The files were taken from the npm package `@netforge/asset-library-files@0.2.0`, which
redistributes Quaternius's own Poly Pizza uploads (meshopt-compressed) and records each
model's source page. Each page below lists the model as Public Domain (CC0).
